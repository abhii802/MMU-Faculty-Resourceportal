A week, in nine resources

— the working story behind this dossier

Monday begins the way most weeks do — with a timetable that has to be right before it can be anything else. Resource 01 is where that starts: a two-minute form replaces what used to be an afternoon of cross-checking rooms, slots and sections, and the linked sheet becomes the single version everyone in the department actually trusts.

By Wednesday, a colleague is unwell and a class needs covering. Resource 02 exists for exactly that hour of the day — a quick adjustment entry so a gap in the schedule never becomes a gap in a student's learning, and a shared log so nobody has to ask twice who is covering what.

Research doesn't wait for a quiet week to arrive. Resource 03 keeps each faculty member's publication targets somewhere visible and specific, rather than somewhere remembered — a running record that turns "I should publish more this year" into a tracked, individual goal.

Then comes the part of the job that takes the longest to start: the blank page. Resource 04 gives that page a first draft — a structured skeleton of a paper, section by section, built the moment a topic is typed in, so the real work of research can begin at editing rather than at staring at nothing.

Tuesday's lecture still needs slides. Resource 05 turns a topic into a clean, presentation-ready deck in the time it takes to make a cup of tea — a starting point built to be reshaped with the examples and emphasis only the professor teaching the room would know to add.

And after the lecture, the notes students actually study from. Resource 06 drafts a well-structured notes document for any Computer Science topic — definitions, explanations, a worked example, and a summary — ready to be annotated, corrected, and handed out as the professor's own.

And when final-year students come asking for project ideas, Resource 07 turns a single technology into a full catalog of twenty fresh, right-sized project briefs — problem statement, tech stack, features and deliverables for each — so no student leaves a meeting empty-handed.

And before Friday's test, thirty questions students haven't seen before. Resource 08 writes a full multiple-choice quiz on any topic, shuffles it, and packages it as one offline file students can take on their own devices — self-graded, no login, no server to manage.

And when the exam cell wants the actual paper, not a quiz. Resource 09 takes the unit-wise syllabus and turns it into a properly formatted Sessional or Final question paper — Sections A through D, scaled by marks — ready to review and print.

04

Research · Draft Assistance

Research Paper Draft Generator

Generates a complete research paper draft, formatted like a published journal article, with real DOI-linked references pulled live from Crossref — the section content still needs your own effort.

How this draft is built

Built using a real, open-source .docx engine — a genuine Word document, formatted to match a real published Springer Nature journal article (running header with page count, unnumbered section headers, hanging-indent reference list, a "DRAFT" banner). Unlike the other generators on this page, the reference list is not template text: your topic is sent to Crossref — a free, public, keyless database of real published papers — to fetch genuinely existing, DOI-linked sources, which are then formatted as a real Vancouver-style reference list with in-text citation markers like [12] or [7, 19] pointing at them. These are real, relevant background papers, not a guarantee that each one supports every specific sentence next to its citation number — read each one and cite it properly wherever it actually applies. If Crossref can't be reached, the list falls back to clearly labelled placeholder entries instead of ever inventing fake citations. The section prose, figures and tables remain illustrative template content either way, so review and rewrite them with your own research before submission.

Quiz Generator

Generates a 30-question multiple-choice quiz.

✓ key saved in this browser
How this quiz is built, and how to get a key from each provider

Unlike the other generators on this page, this one calls an AI provider's API directly from your browser using your own key, so the questions are genuinely written for the topic you type rather than assembled from a template — the topic (not the key) is what gets sent. Each provider's key is stored only in this browser's local storage, in its own slot: never written into the downloaded quiz file, never sent anywhere else, and switching providers in the dropdown never touches the other two keys.

Google (Gemini) — try this first if you're out of credit elsewhere: go to aistudio.google.com/apikey and sign in with a Google account → click Create API key (choose or create a Google Cloud project if prompted) → copy the generated key (starts with AIza). Gemini has a genuine, ongoing free tier — no card, no expiry, generous daily limits — the only real "free" option of the three. It can still occasionally block direct browser requests (CORS) for some accounts; if so, try Anthropic instead.

Anthropic (Claude) — the most consistently reliable option here: go to console.anthropic.com and sign in or create a free account → open Settings → API Keys → click Create Key, name it anything, and copy the key (starts with sk-ant-). New accounts get a small one-time free trial credit (around $5, phone verification, no card needed) — once that's used up, add credit under Plans & Billing to keep going.

OpenAI (ChatGPT): go to platform.openai.com and sign in or create a free account → open API keys in the left sidebar → click Create new secret key, name it anything, and copy it (starts with sk-). OpenAI no longer gives free trial credit to new accounts, so a small top-up under Settings → Billing is needed before this key will work at all — and like Google, OpenAI also blocks direct browser requests for some accounts (CORS), so it may still fail even when funded.

Assessment · Draft Assistance

Exam Question Paper Generator

Generates a properly formatted Sessional or Final question paper as a real .docx — Sections A–D, scaled by exam type, built from the unit-wise syllabus topics you enter.

How this question paper is built

Built entirely in your browser using the same real, open-source .docx engine as the research paper and notes generators above — no server, nothing uploaded. Section A asks short-answer questions (1 mark each), through to Section D's long-answer questions (6 marks each), cycling through the topics you list for each unit with a bank of exam-style verbs ("Define…", "Explain in detail…", "Critically discuss…") so questions vary even when a topic repeats across sections. Review every question before printing — the phrasing is templated, not a substitute for the paper setter's own judgement on emphasis and difficulty.
